# Moochy guides

Moochy lets developers donate a capped slice of their own LLM API budget to open-source projects, and lets maintainers use it from any AI client or agent. Your API key never leaves your machine, and every request is end-to-end encrypted.

**Open-source client (Apache-2.0) · 100% free.** No fees, no commission, no paid tier. Donors pay their own provider directly; Moochy never touches money.

| Guide | For |
|---|---|
| [Donor guide](donor.md) | Install, sign in, add a provider key, set your limits, donate, pause, reclaim, read your journal |
| [Maintainer guide](maintainer.md) | Claim a repository, approve donors, manage members, connect your tools |
| [Integrations](integrations.md) | Exact configuration for OpenCode, Claude Code, Cursor, Cline, Continue, Zed, Goose, Windsurf, VS Code, Claude Desktop, Aider, agent frameworks, and SDKs |
| [Running a headless node](headless-node.md) | Always-on donor on a server or container; agents in CI |
| [FAQ](faq.md) | Open source and free, privacy, the security model in plain words |
